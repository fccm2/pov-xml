.pov to .xml, tutorial

pov-xml tries to provide an .xml syntax equivalent than the original .pov

here is an example,

test5.xml

<povx>

  <background>
    <color rgb='0.2, 0.1, 0.4' />
  </background>

  <camera location='1.8, 4.8, 2.4' look_at='0, 0.6, 0' />

  <light_source position='2, 4, -3' color='0.4, 0.5, 0.6' />

  <global_settings>
    <ambient_light rgb='0, 0.3, 0.6' />
  </global_settings>

  <sphere position='0, 0.8, 0.2' radius='0.2'>
    <texture>
      <pigment>
        <color rgbt='0.1, 0.2, 0.9, 0.1' />
      </pigment>
    </texture>
  </sphere>

  <box corner1='0.1, 0.6, 0.1' corner2='0.6, 0.7, 0.8'>
    <texture>
      <pigment>
        <color rgbt='0.1, 0.2, 0.9, 0.1' />
      </pigment>
    </texture>
  </box>

</povx>

the command ./xpov.opt transforms test5.xml, into test5.pov,

test5.pov

background { color rgb <0.2, 0.1, 0.4> }

camera {
  location <1.8, 4.8, 2.4>
  look_at <0, 0.6, 0>
}

light_source { <2, 4, -3> color rgb <0.4, 0.5, 0.6> }

global_settings { ambient_light rgb <0, 0.3, 0.6> }

sphere {
  <0, 0.8, 0.2>, 0.2
  texture {
    pigment { color rgbt <0.1, 0.2, 0.9, 0.1> }
  }
}

box {
  <0.1, 0.6, 0.1>,
  <0.6, 0.7, 0.8>
  texture {
    pigment { color rgbt <0.1, 0.2, 0.9, 0.1> }
  }
}
